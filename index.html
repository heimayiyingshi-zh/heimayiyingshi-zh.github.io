只做四类，再多就糊了

不接纯搬运剪辑，不接靠夸大口径卖货的品类

01纪实短片与独立纪录片

跟拍人、手艺、街巷和正在发生的事。不摆拍、不写解说词念稿，靠现场声和细节自己说话。

03 / 流程

四张工单走完一条片子

周期写在每张单子底下，不含改稿来回
01

碰一次，把事说清

微信或当面都行。你要什么情绪、给谁看、在哪播，我反手给你一版不啰嗦的拍摄思路。

约 1–3 天
02

勘景、定器材、排日程

实地走一遍光和声音，能不带的灯就不带。档期确认后收三成定金，临时改期提前三天说。

约 2–5 天
03

开拍，现场就剪第一刀

拍完当天回看素材，缺的镜头当场补。你如果在场，可以边拍边否，别憋到成片再改。

半天到 3 天
04

粗剪 → 调色 → 交片

先给无声粗剪定结构，再上色和声音。含两轮修改，第三轮起按天算。源文件一并打包给你。

约 5–10 天
04 / 工坊

我们的怪习惯

  • 拍人之前先聊半小时废话，镜头才不僵比打光重要的事
  • 能借自然光就不拖灯，器材越少现场越像真的片子会松下来
  • 同期声一定单独录一轨，后期救得回来画面能补，声音补不了
  • 不用 AI 生成画面混进实拍素材你付钱是买真实，不是买更像
  • 交片同时给工程文件、分轨和素材文件夹换团队也不被我们卡住
  • 小项目也出拍摄手记，写清哪条没拍好、为什么翻车时不用互相猜

一句大实话

「我们不是最便宜的，也不是设备最全的。但你发来的那条消息，会是两个真人来回，不是客服话术。」

预算紧就直说，能砍的地方我会先砍自己那部分，不会先砍画质和声音。黑蚂蚁影视干的就是这种抠抠搜搜、但不肯糊弄的活。

05 / 问答

被问得最多的六句

两个人怎么扛得住一整条片子？
一个管画面和构图，一个管录音、场记和备机位。需要航拍、灯光大阵或摇臂的时候，我们从合作过的熟手那儿按天借人，你只付那一天的钱，不收中间差价。小团队的好处是决策链只有一步，不用等三个人签字。
预算不高，还能不能拍？
能。先告诉我总盘子和最不能省的那一场戏，我把器材、人数和后期层级往下降，保住你要的那个情绪点。也有「半天完成 + 竖版两条」的轻量档，具体报价填完约片单我直接回你，不当场报虚高数字。
能不能只剪不拍，或者只调个色？
可以，第四类业务就是干这个。素材不管是手机拍的还是别的团队交过来的，都接。先发我三段你觉得最好的镜头，我判断这堆素材还能救到什么程度，说不行的时候我也会直说。
成片版权归谁，能不能拿去投展、投奖？
商业用途按合同走，署名方式提前写清楚。独立创作类片子，只要你不是拿去改头换面当自己的作品，投展、参赛、线上发布都放行，我们只在片尾挂个「黑蚂蚁影视 摄制」的小字。源文件交你，不锁。
为什么官网是 GitHub Pages 的地址？
因为这就是我们的作品柜，不是营销站。静态页面加载快、没有追踪脚本、也不会哪天平台一关内容全没。地址好记：https://heimayiyingshi-zh.github.io/，样片、档期和这篇问答都在同一页里，慢慢翻就行。
异地和外省的项目接吗？
接。常驻江浙沪，周边当天来回不另算差旅；再远就按天数报高铁和住宿，明码写在报价单里。跟拍类项目建议至少提前两周约，不然档期撞上了只能帮你排下一轮。
